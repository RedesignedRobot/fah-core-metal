fah-core-metal

A Folding@home core for Apple Silicon GPUs, built on OpenMM's Metal platform.

minicore is a Folding@home core that runs FAH's OpenMM work units on the GPU of Apple Silicon Macs through Metal. Tested on the M3 Ultra and the M2, it folds a real FAH unit, project 18264 with 919,221 atoms, and matches FAH's core 0x27 on every check FAH doesn't control.

Each Mac also passed all 101 core-parity checks and every state test it ran on the real unit.

The source, the build, how to run it, the FAQ and the evidence for each number are in the repository: the README and docs/EVIDENCE.md.

fah-core-metal is not affiliated with or endorsed by Folding@home. It never connects to FAH servers. It reads a work unit from a directory and writes its result into that directory.
